# Support

Open **Help…** in the menu bar for offline guidance, or **Quick Start…** for
Accessibility and startup setup. Help’s **Edit Shortcuts…** opens the shortcut
editor directly. Start with the [README](README.md) for setup and everyday use. The detailed guides
cover [configuration](docs/configuration.md), [troubleshooting](docs/usage.md#troubleshooting),
and [AppleScript](docs/scripting.md).

If you are still stuck, search [existing issues](https://github.com/jpwinans/paneglide/issues).
Open an issue with your PaneGlide version (menu → About PaneGlide), macOS version,
affected application, display setup, and the steps you tried. Use the
[bug or feature template](https://github.com/jpwinans/paneglide/issues/new/choose)
where it fits; a blank issue is available for usage questions.

Share only the settings and screenshots needed to explain the problem. Remove
private window contents, account information, and credentials before posting.

For security concerns, use the [private reporting route](SECURITY.md).
