# PaneGlide documentation

PaneGlide runs in the macOS menu bar and acts on the focused application window.

| Guide | What it covers |
| --- | --- |
| [Installation](installation.md) | Requirements, app installation, source builds, Accessibility, startup, and removal |
| [Configuration](configuration.md) | General settings, shortcuts, display profiles, margins, partitions, Center, and alternate widths |
| [Usage](usage.md) | Default shortcuts, the three-window workflow, SnapBack, monitor transfers, and troubleshooting |
| [AppleScript](scripting.md) | Individual window commands, grids, thirds, tiling, and cascading |
| [Release packaging](releasing.md) | Maintainer instructions for signed release packages |
| [Tests](../Tests/README.md) | Local automated checks and native test setup |

For a first setup, follow Installation, then configure Window Sizes for each display.
